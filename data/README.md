# data/

Local working data. Everything in this folder except this file is git-ignored.

- `raw/<story>/`: NISAR GCOV `.h5` files from `asaase download <story>` (several GB each)
- `work/`: quicklooks and intermediates from `asaase quicklook <story>`

The processed layers the app shows live in `web/public/data/` and **are** committed.
